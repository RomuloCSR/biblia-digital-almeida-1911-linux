# Bíblia Digital Almeida 1911 em PT-BR (Linux)

Texto bíblico baseado na edição **Almeida 1911 (Domínio Público)**, com atualização ortográfica e gramatical para o Português do Brasil realizada em **11/2026**.

- **Objetivo:** Motor leve e rápido de navegação bíblica para Linux, sem anúncios e 100% offline.
- **Autor:** Romulo CSR ([github.com/RomuloCSR](https://github.com/RomuloCSR))
- **Apoio espontâneo via PIX:** `21980934118`

---

## Como baixar e usar (Passo a passo rápido)

### 1. Baixar o projeto
- Clique no botão verde **`<> Code`** no topo desta página e depois em **`Download ZIP`**.
- Extraia o arquivo `.zip` em qualquer pasta do seu Linux (por exemplo, em `Documentos`).

### 2. Abrir a Bíblia (Sem precisar digitar comandos)
1. Abra a pasta extraída no seu gerenciador de arquivos.
2. Clique com o **botão direito** sobre o arquivo **`Abrir_Biblia.sh`** e escolha **Executar como Programa**.
3. A janela de leitura abrirá automaticamente.

*(Opcional — via terminal: abra o terminal dentro da pasta e execute `./motor.biblia` ou recompile com `gcc -O2 motor.biblia.c -o motor.biblia`).*
